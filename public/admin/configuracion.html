Cámara ANPR (ingreso automático) Desactivado
La lectura de placas la realiza la cámara ANPR Dahua. ParkSystem solo recibe el evento de la cámara y registra el ingreso; no usa inteligencia artificial ni OCR propios en este modo.
Rotarlo invalida la URL usada por la cámara.
Si se define, solo se aceptan eventos desde esta IP.
Aparecerá como quien registró el ingreso.
Último evento recibido: Aún no se ha recibido ningún evento.

  1. Selecciona el usuario de registro y pulsa Guardar.
  2. Pulsa el ícono de llave para generar el token de seguridad.
  3. Copia la URL del webhook generada arriba.
  4. Entra al website de la cámara por su IP, ve a la sección ITSAPI / Platform / notificación HTTP y pega esa URL.
  5. Activa el switch "Activar ingreso automático" y guarda.
  6. Pasa un vehículo frente a la cámara y verifica el último evento aquí.

Cámara y servidor deben estar en la misma red local. El tipo de vehículo (carro/moto) se determina automáticamente por el formato de la placa colombiana detectada por la cámara.

Inteligencia Artificial (Lector de placas) No configurado
No hace falta elegir a mano: deja el recomendado, pega la clave y pulsa Probar conexión. Si tu cuenta no admite ese modelo, el sistema prueba otros y te deja el que sí funciona.

Solo necesitas una API Key. El modelo ya viene elegido.

  1. Entra a Google AI Studio e inicia sesión con Google.
  2. Clic en Create API key (crear clave de API).
  3. Copia la clave (empieza con AIza…) y pégala arriba.
  4. Deja el modelo en Rápido (recomendado).
  5. Pulsa Probar conexión y luego Guardar.

Si la prueba dice que el modelo no está disponible, no lo cambies a mano: el botón ya busca uno compatible con tu clave. Cuando encuentre uno, pulsa Guardar.

El plan gratuito de Google tiene cupos bajos y el lector puede dejar de responder. Para un parqueadero en producción conviene activar facturación en AI Studio → Uso y facturación (la misma clave sigue sirviendo). La clave se guarda cifrada y nunca se muestra completa después de guardarla.
